# PKOS 主人手册

这里用中文说明项目进展、日常启动和待确认事项，不替代治理规则或工程合同。

1. [当前状态](status.md)：哪些已提交、哪些仍在工作区、哪些尚未验证。
2. [如何运行](how-to-run.md)：使用既有配置启动，避免连错数据或实例。
3. [已知问题](known-issues.md)：当前限制、影响和验收缺口。
4. [决策与边界](decisions.md)：路线选择、明确不做项和待裁决事项。

Web Dashboard 是人工管理面，Desktop 是日常交互面；Mobile 目前只是独立兼容性测试壳，不等于完整手机客户端。

开发与 Agent 协作从[工程文档索引](../docs/README.md)进入；权限以[项目宪法](../AGENTS.md)及领域合同为准。本手册不新增写回权限，也不自动修改知识状态。
